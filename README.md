# 동네서랍 — 월계1동 아이디어 수요 검증·기록

> 2026 KW해커톤 40조 **월계획** · 주제: 청년·지역 상생

월계1동에서는 광운대 캡스톤, 지역연계 수업, 공모전, 주민 제안으로 지역 문제 해결 아이디어가 꾸준히 나옵니다.
하지만 실제 주민이 원하는지 확인할 방법이 없고, 멈춘 이유가 기록되지 않아 다음 시도가 처음부터 다시 시작합니다.

동네서랍은 아이디어를 **검증 카드**로 올려 주민의 **단계형 수요 반응**(괜찮다 → 써볼 것 같다 → 이 가격이면 쓰겠다 → 알림 신청)을 모으고,
**검증 리포트**와 **결론(진행·보류·중단 + 사유)**을 기록해 응답자에게 돌려주며, 멈춘 카드를 다음 팀이 **이어받게** 합니다.

## 동작하는 기능 (MVP)

| 흐름 | 화면 | 내용 |
|---|---|---|
| 카드 등록 | `/new` | 자유 서술 → 대상·장소·기대 효과 초안(규칙 기반, `OPENAI_API_KEY` 설정 시 AI) → 유사 과거 카드 제시 → 확인 후 게시, 검증 기간 1~8주 |
| 수요 반응 | `/cards/[id]` | 4단계 반응(기기당 1회, 수정 가능), 3단계 선택 시 희망 가격, 거주/직장·학교/방문 구분, 브라우저 위치로 월계1동 경계 안 확인(좌표 미저장) |
| 의견 | `/cards/[id]` | 찬성·반대·조건부 찬성(조건 필수), 신고 |
| 검증 리포트 | `/cards/[id]` | 단계별 분포(5명 미만이면 비율 숨김), 희망가 중앙값·범위, 응답자 구성, 비공식 조사 고지 상시 표시, 제안자 확인 후 공개 |
| 결론 기록 | `/cards/[id]` | 진행·보류·중단, 보류/중단은 사유 태그+사유 필수, 이력 보존, 응답자 전원에게 알림 |
| 이어받기 | `/cards/[id]/takeover` | 보류·중단·정체 카드를 원본 연결로 재시작, 달라진 점 필수, 원 응답자에게 재시작 알림 |
| 기록 탐색 | `/` | 검증 중 / 결론·종료 탭, 검색, 시드된 과거 공개 아이디어 |
| 내 참여 | `/me` | 로그인 없는 기기 참여 기록, 알림(읽음 처리), 닉네임 |
| 운영 | `/admin` | 운영 코드로 진입, 신고 가리기/유지(기록), 시연용 검증 즉시 종료 |

## 실행

```bash
pnpm install
cp .env.example .env.local   # OPERATOR_CODE 설정 (예: demo-op)
pnpm dev                     # http://localhost:3000
```

- `DATABASE_URL`을 비우면 `./.data/pglite`에 로컬 Postgres(PGlite)가 자동 생성되고 시드 데이터가 들어갑니다.
- 배포 시에는 `DATABASE_URL`에 Postgres(Neon/Supabase 등) 연결 문자열을 넣으면 같은 스키마로 동작합니다.

```bash
pnpm test        # 도메인 규칙 단위 테스트 (vitest)
pnpm typecheck   # tsc --noEmit
pnpm lint
pnpm build
```

## 고지

동네서랍의 반응과 리포트는 비공식 의견 조사로, 공식 결정이 아니며 대표성을 보장하지 않습니다. 공식 민원 접수나 법적 동의 절차를 대신하지 않습니다.
