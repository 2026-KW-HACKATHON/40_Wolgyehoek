# 서비스 UI 보완 · 2026-10-06

사용자가 선택한 목표는 해커톤 시연에서 **완성도 높은 서비스 인상**이다. 기존 주민 참여 기능과 장끼의 공용 컴포넌트를 유지하면서 화면 위계와 동네서랍의 브랜드 표면을 보완했다.

## 변경

- 첫 화면: 큰 브랜드 제목, 따뜻한 주황/크림색 강조, 참여 가능한 카드와 바로 참여하는 버튼.
- 기존 목록에 묻혀 있던 원본→이어받기 관계를 별도 영역에서 실제 카드로 연결. 관계가 없는 DB에는 서비스 흐름 안내를 표시.
- 집계는 Spring의 저장된 데이터로 계산하고 예시 카드를 제외. 참여자 수를 임의로 만들지 않으며, 같은 사람이 여러 카드에 반응할 수 있어 단위를 반응 ‘건’으로 표시.
- 검색/상태 필터 사용 시 소개 영역을 접어 검색 결과에 집중. 빈 결과와 첫 등록 안내 제공.
- 카드: 장소·상태, 제안자, 제목, 결론 사유, 반응/의견 수, 다음 액션 순서로 정리.
- 상세: 실제 상태를 기준으로 제안·반응·공개 리포트·결론을 표시하는 기록 흐름. 예시/공개 전 권한은 기존 그대로.
- 작성: 큰 안내 제목과 등록 단계. 내 참여: 기록/알림 요약, 소식, 빈 상태의 다음 행동, 닉네임 설정.
- 서랍 형태의 SVG 브랜드 마크, 일관된 모서리·여백·타이포, 전환 중 로딩 표시, 라디오/체크박스 선택 영역의 키보드 포커스 표시.

브랜드 색과 표면은 `app/globals.css`의 토큰이다. 장끼 Button/Input/Textarea/Badge/Card/Tabs를 계속 재사용한다. 새 화면은 React 컴포넌트이며 이미지로 만든 화면이 아니다. 서버 API, 데이터베이스, 정책은 변경하지 않았다.

## 검증

- 프론트 도메인 테스트 19개, 타입 검사, ESLint, webpack 운영 빌드 통과.
- 운영 빌드의 탐색·작성·내 참여·종료 카드·검증 중 카드: 1440px / 375px / 320px에서 가로 넘침과 브라우저 오류 없음.
- 실제 Tailscale HTTPS에서 상태 탭, 검색 결과, 상세 이동, 빈 가격 거부, 조건 누락 시 입력 보존, 문장→초안, 닉네임 저장, 공개 리포트/기록 흐름 확인.
- Aside에서도 실제 운영 화면과 검색/탭 동작 확인. 모바일 크기 검증은 별도 자동 브라우저 사용.
- 기능 확인 과정에서 새 카드/수요 반응/의견은 게시하지 않았다. 닉네임 변경은 별도 검증 기기에만 수행했다.
