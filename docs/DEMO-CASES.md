# 시연 카드의 근거 (2026-10-07)

발견 화면의 '시연 카드 받기'(`POST /api/credits/samples`)가 만드는 카드 6장은 월계1동·광운대 주변의 공개된 사안을 출발점으로 삼았다. 카드는 모두 `시연` 표시(is_seed)와 '동네서랍 시연 팀' 제안자로 구분되며, 실제 주민 응답이나 실행 계획이 아니다.

각 카드의 **확인된 사실**은 아래 출처에서 확인한 내용이고, **가설**은 팀이 세운 문제 정의와 해결 아이디어다. 발표에서는 가설을 사실처럼 말하지 않는다.

카드를 고칠 때는 `backend/.../credits/CreditService.java`의 `samples()`와 이 표를 함께 고친다. 이전 시연 카드 3장(`demo_walk40`, `demo_lunch40`, `demo_repair40`)은 새 세트를 준비할 때 모집을 마감하며, 기존 참여 기록은 지우지 않는다.
